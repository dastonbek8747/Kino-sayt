# Django Movie Site

> A Django website for movies, anime, cartoons and series, with a catalogue and detail pages.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Catalogue split by category (movies, anime, cartoons, series).
- Detail pages with poster and description.
- Django admin for content management.
- Search and category filters.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Django |
| Database | SQLite |
| Frontend | Django templates, CSS |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/django-movie-site.git
cd django-movie-site
python -m venv .venv && source .venv/bin/activate
pip install django
python manage.py migrate
python manage.py runserver
```
